Pro Research

ChatGPT Pro Research

chatgpt-pro-research

用真实 ChatGPT Pro 网页会话，做无人值守多轮调研。

  • 研究卡先确认问题、材料与成功判据
  • 设定轮次上限，状态机与回执记录过程
  • 生成 final.md，汇总本轮记录

  brief="比较方案与风险", criteria=["列明方案取舍"],
  materials=[], rounds=3)

两个插件共用浏览器 profile、执行队列、记录与安全护栏，不需要分别维护登录状态。

产物保存到本地

产物保存在本地，记录按项目归档。原始答复默认只存本机；只有显式配置后才复制进项目。

不自动重发

提交状态未知时，停下等待人工核对。保留回执和现场线索，确认之后再继续。

提交前密钥扫描

扫描命中即阻断，不发送命中的材料。材料经真实网页提交，提交前请确认内容边界。

三步开始

三步完成一个任务。

你定义问题与判据，插件推进轮次。
结果是否采用，仍由你裁决。

1

填写任务卡

写清问题、材料、成功判据和轮次上限，确认后开始执行。

2

无人值守执行

排队进入真实网页会话，逐轮留下回执；状态异常时停下来请你核对。

3

查看并裁决

在侧边栏查看记录与产物，审阅结论或设计，决定下一步。

安装

安装到 DSH。
完成一次登录。

两个插件可分别安装。
共用登录状态，登录一次即可使用。

运行要求

已安装 DeepSeek Harness，并有可用的 ChatGPT Pro 网页订阅会话。运行期间 DSH 保持打开，可最小化；不承诺关机后继续运行。

chatgpt-pro-research
dsh plugin --profile desktop add chatgpt-pro-research
gpt-image-design
dsh plugin --profile desktop add gpt-image-design

一次性登录

安装后，让 DSH 中的 agent 调用任意一个已安装插件的登录工具；在弹出的浏览器窗口中完成登录。两个插件共用同一 profile，登录失效时需重新登录。

通过 Pro Research 登录
pro_research(action="login")

或者，通过 Image Design 登录：

通过 Image Design 登录
gpt_image_design(action="login")

命令可直接复制；登录调用交给 DSH 的 agent 执行。

使用边界

先了解使用边界。

dsh-pro 是 DeepSeek Harness 的插件仓库。这是订阅网页自动化，不是官方 API，不代表 OpenAI / ChatGPT 的官方产品或背书。

  • 服务条款（ToS） · 自动化网页可能违反服务条款，使用者需自行评估并承担风险。
  • 账号风控 · 自动化可能触发风控或导致账号受限。
  • 页面改版 · 网页结构变化可能使自动化失效，需要维护与人工介入。

不绕过验证码 / 2FA。遇到验证，请由本人完成。
