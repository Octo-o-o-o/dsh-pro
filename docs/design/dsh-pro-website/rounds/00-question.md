# dsh-pro website

## 研究问题

为 dsh-pro 的两个 DSH 插件（chatgpt-pro-research、gpt-image-design）设计一个统一官网：3 个视觉方向 + 可运行的单文件 HTML demo。

## 成功判据

- 3 个方向各 1 张 1440 宽桌面整页概念图，版式/配色/叙事实质不同，不是同稿换色
- 每张图都准确出现 chatgpt-pro-research 与 gpt-image-design 两个包名，以及 0.2.0、MIT、非官方 API 风险信息
- 首屏清楚表达：真实网页会话、无人值守、产物本地、非官方通道，至少覆盖 3 项
- 至少 1 个单文件 HTML demo，1440/390 宽可用，无外链依赖，文案准确，对比度达 AA
- HTML demo 含两条正确安装命令、一次性登录、三条护栏、首屏与页脚风险声明
- 不使用 OpenAI/ChatGPT 官方 logo，不使用 AI 渐变/玻璃拟态/假数据

## 任务

你是资深产品设计师兼前端工程师。为开源项目 dsh-pro 设计官网（中文优先），目标是让 DSH 用户和 GitHub 访客在 5 秒内理解两个插件的关系与价值，并能直接复制安装命令。

【必须准确的事实，不要发挥】
- dsh-pro 是 DeepSeek Harness (DSH) 的插件仓库，MIT，版本 0.2.0，作者 Octo-o-o-o，GitHub: https://github.com/Octo-o-o-o/dsh-pro
- 插件一：包名 chatgpt-pro-research，界面名 ChatGPT Pro Research，短名 Pro Research。用真实 ChatGPT Pro 网页会话做无人值守多轮调研：研究卡、轮次上限、状态机、回执、final.md；侧边栏面板列出主题/轮次/状态/记录路径。
- 插件二：包名 gpt-image-design，界面名 GPT-Image Design，短名 Image Design。复用同一通道生成设计图与前端 HTML demo，产物存本地，侧边栏画廊预览；有设计卡、轮次、裁决。
- 两者共用同一浏览器 profile（~/.dsh/pro-research/browser）、同一执行队列、同一套记录与安全护栏。
- 共同护栏：提交状态未知绝不自动重发；密钥扫描命中即阻断；原始答复默认只存本机；记录按项目归档。
- 风险：这是订阅网页自动化，不是官方 API；页面改版、账号风控、ToS 风险由使用者承担；不绕过验证码/2FA。
- 安装命令：
  dsh plugin --profile desktop add chatgpt-pro-research
  dsh plugin --profile desktop add gpt-image-design
- 一次性登录：pro_research(action="login") / gpt_image_design(action="login")
- 必须区分清楚：不是聊天 UI，不是模型代理，不是官方 API。不要出现“官方”背书措辞，不使用 OpenAI/ChatGPT 官方 logo。

【受众】DSH 现有用户、开发者、从 GitHub / 插件市场来的访客，尤其在意“本地留档、断了能恢复、卡住才叫人”的人。

【单页结构，顺序固定】
1. 顶部导航：dsh-pro 字标、研究 / 设计 / 安装 / 风险锚点、GitHub 链接、0.2.0 版本徽标。
2. Hero：eyebrow「DSH PLUGINS · 0.2.0 · MIT」；主标题「让 ChatGPT Pro 在 DSH 里上夜班。」；副标题「两个插件，一条真实网页会话。把几十轮调研和设计迭代交给 Pro，产物留在本地，卡住才叫你。」；双 CTA「安装插件」「看它怎么工作」；一行风险小字；右侧“会话控制台/回执”视觉，表达队列、第 03 轮、answered、artifacts 路径，但不要假 KPI。
3. 两张产品卡：Pro Research / GPT-Image Design。各含一句话定位、3 个能力点、工具调用片段、产物路径、侧边栏面板名。
4. 「一条通道，两种产出」：共用 profile / 队列 / 记录；三条护栏卡片：本地留档、绝不自动重发、提交前密钥扫描。
5. 「三步」：写卡确认 → 无人值守跑 → 回来裁决。
6. 安装：两条命令 + 一次性登录 + 运行要求（DSH 保持运行，可最小化）。
7. 风险声明：非官方 API、ToS、账号风控、页面改版；不绕过验证码/2FA。
8. 页脚：MIT、GitHub、作者、Built for DeepSeek Harness。

【3 个视觉方向，必须实质不同，不是同稿换色】
A「深夜实验台」：墨黑 #0A0C10 底，细网格/刻度线，等宽字体标签，薄荷绿 #5FE1B6 作研究色，琥珀 #F0B45E 作设计色；冷静、精确、有仪器感；中文无衬线大标题，紧凑字距。
B「档案编辑部」：暖纸色 #F3EFE6 底，黑墨文字，衬线大标题（中文宋体回退），信号红 #D64B3C 点缀，回执/印章/编号/横线，像研究档案；克制、有人味。
C「双通道」：石墨 #14171D 底，左侧研究青 #4FD1C5，右侧设计珊瑚 #F08A6C，两条垂直轨道在中间汇入一条通道；分屏构图，强对比，直接表达“两个插件共用一条通道”。

每个方向给 1 张 1440 宽桌面整页概念图（竖版 3:4 或 2:3，至少包含首屏、两张产品卡、安装区）。图中中文可以示意，但两个包名、两条安装命令、0.2.0、MIT 必须准确可读。禁止 AI 紫蓝渐变、玻璃拟态、漂浮光球、假数据仪表盘、通用 SaaS 模板感。

【HTML demo 要求（第 2 轮按选定方向产出；若本轮能一并给更好）】
- 完整单文件 HTML，内联 CSS/JS，双击可开，无构建步骤。
- 1440 与 390 宽均可用、无横向滚动；移动端导航可折叠。
- 无外链字体、图片、JS、CSS；图标用内联 SVG；系统字体栈。
- 正文对比度 ≥ 4.5:1；键盘可操作；尊重 prefers-reduced-motion。
- 文案与上述事实一致，不编造数字；风险声明在首屏和页脚都出现。
- 命令块带复制按钮；锚点导航可用；不要假表单/假注册。
- 以单个 ```html 完整代码块输出，不要省略。
