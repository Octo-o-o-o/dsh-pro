目标是成熟桌面工具的安静、精确、清晰，用户找到任务后先读成果，再处理状态，必要时追溯过程。
当前 A 的落地：280px 主题列表（搜索、四筛选）；详情顶部大边框卡片约164px高，标题/元数据/停止原因/绝对路径/独立按钮行；下方概览/轮次/产物 tabs。Research 概览中间是七列轮次表，右侧276px栏重复放最终文档与全部产物，以及主题信息，因此大量空白且结果藏在边栏。Design 概览为全图片小网格、demo卡片，右侧重复缩略图与文件。深色面板列表背景过亮，卡片边框层层嵌套，状态过饱和，许多文字仅10px。

## 本次推荐方案，先 review 再给定稿 demo
- 共享 272–288px 任务导航，搜索32px、可读的状态筛选、任务标题两行、状态/轮次/时间分两行，选中用单一强调线与浅背景；普通完成行不画强状态条。
- 详情头为紧凑无外框页头：面包屑式轻量上下文、20px标题、状态、一行元信息；主动作最多一个明显填充按钮，次操作至多两个，工具和危险操作进更多。完整路径进入可折叠主题信息。异常原因用独立克制提示。
- Research 概览：主列为最新总结的文档阅读预览（从已有 /file 读 final.md，React安全文本/markdown结构，不执行HTML；加载/失败/空态）+ 阅读全文入口；旁边或下方为最近轮次摘要与主题信息。完整轮次表仅在轮次页，不在概览铺宽表。final.md 不重复列两次。不把已取消或失败主题的文件称为验收通过。
- Design 概览：最新一轮图片为有呼吸感的画廊（完整 contain 展示，不裁切设计图，图下注释），demo 入口放紧邻画廊，文件与运行信息次要。全部图片和旧版本在产物/轮次页追溯。无图片时显示真实空态，不造图片。
- 卡片仅用于真实内容分组；减少套框。中文12–14px正文、12px辅助文字、16/20/24px节奏，蓝灰研究/暖铜设计点缀，状态文字加图标。
- 保留全部已有动作、轮询与真实后端；不给新建任务按钮造接口。已存在裁决查看和删除主题入口保留；删除必须二次确认。
- 使用面板容器宽度决定布局（DSH左侧还占280px），宽屏详情可两列，面板<1080收单列，<720导航与详情切换+返回任务按钮，不能让顶部任务列表占走半屏。320px可用。
- 具备 focus-visible、键盘选择、Esc关闭、对话框焦点约束与返回、按钮pending禁重入、错误重试、长中文/路径换行、图片加载失败与减少动效支持。
