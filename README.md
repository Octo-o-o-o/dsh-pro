# dsh-pro

用 ChatGPT Pro 网页会话做**无人值守的多轮调研与设计**的 DeepSeek Harness 插件。

状态：**设计阶段，尚不可用**。当前仓库只有设计文档，没有可安装的包。

> ⚠️ 风险提示：本插件驱动的是 ChatGPT 网页（订阅额度），不是官方 API。自动化网页可能违反服务条款、触发风控或导致账号受限；页面改版也会让它失效。请自行评估账号风险，不要把凭据写进仓库或日志。

## 它要解决什么

- 一轮要十几到几十分钟、可能多轮，人不能守着：发出去，卡住才叫你。
- 用订阅额度而不是 API token：通道是真实网页会话，不是模型代理。
- 材料准备麻烦：一次性列出清单、核对上传，而不是每次手工拼。
- 历史散落：按项目/主题记录每轮问题、材料、答复、裁决和产物。

## 计划中的用法

```text
/pro-research 我要决定 X，先调研社区现状和风险
/pro-design 登录页改版，给我三个方向和取舍
```

DSH 先给一张研究卡（问题、材料、轮次上限、产物路径），确认后后台跑；侧边栏可看轮次、状态和产物；卡住时只通知一次，并留下可续的现场。

## 仓库结构（计划）

```text
packages/
  core/          # 任务引擎、状态机、记录、传输接口
  transport/     # ChatGPT 网页驱动（独立子进程）
  research/      # Pro 调研插件 + 技能 + 产物模板
  design/        # Pro 设计（第二阶段）
docs/
  design.md      # 设计文档
```

第一阶段只发布 Pro 调研；设计流程复用同一核心。整套 OctoWorkFlow 的约定和交付/评审技能，等前两个入口有真实反馈后再作为独立插件提供。
