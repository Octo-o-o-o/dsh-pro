## 看什么

1. `topic.json` 里的状态、轮次、判据是否与面板一致；
2. 裁决是否逐条对应判据，而不是一句“看起来不错”；
3. 产物是否真的能打开，缺图/缺 HTML 时记录有没有说清楚；
4. 失败或取消的主题有没有保留现场，而不是伪装成完成。
